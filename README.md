# A Narrative-Driven Technical Support Simulation Game Using Finite State Machine for Cybersecurity Literacy

This project solves the "awareness-action gap" in traditional, passive cybersecurity training for corporate employees and non-technical personnel by providing an immersive, narrative-driven 3D helpdesk simulation powered by an Event-Driven Finite State Machine (FSM) to build practical threat detection skills against social engineering attacks

## Problem statement
Corporate employees and non-technical personnel remain highly vulnerable to sophisticated social engineering attacks that exploit cognitive biases through tactics like artificial urgency, panic, and fake authority. As a result, human error contributes to 60% to 68% of global data breaches, incurring average breach costs exceeding $4.88 million alongside significant operational disruptions. Traditional cybersecurity training programs rely on passive slides and annual compliance videos, creating an "awareness-action gap" that fails to equip users with practical decision-making skills under live pressure. Without immersive, scenario-based learning such as a narrative-driven helpdesk simulation governed by an Event-Driven Finite State Machine (FSM) organizations remain unable to foster the active threat detection habits necessary to prevent costly compromises.
